# Development archive

These files preserve the original project sources, development notes, and Streamlit assets from before the package restructuring, including pre-existing local edits. They provide research history and are not installed by `pip install .`.

The supported workflow is in `src/agens3/` and is invoked with `agens3`. Archived prototypes retain their original paths and dependency assumptions. The old Pipfile and lockfile describe the earlier UI environment, not the current package. Development notes may describe alternate architectures or experiments rather than current behavior.
